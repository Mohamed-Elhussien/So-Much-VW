# تسليم الداتا الحقيقية — إيه اللي المفروض تتقال للشخص اللي هيبعت الداتابيز

المشروع دلوقتي شغال بالكامل على الـ Schema اللي في
`server/src/models/Product.js`. أي حد هيبعتلك داتا حقيقية (منتجات
جديدة، أو داتابيز كاملة بديلة)، المطلوب منه إنه **يطابق نفس شكل
الحقول دي بالظبط**، مش شكل تاني. لو الداتا جاية بشكل مختلف، ابعتهالنا
وهنظبط الكود يتوافق معاها، بدل ما تحاول تحوّلها إنت بنفسك.

## الحقول المطلوبة لكل منتج

```js
{
  name: "Cybele Matte Lipstick",       // مطلوب
  category: "lipstick",                 // مطلوب — lowercase، بدون مسافات (استخدم "-" بدل المسافة)
  department: "makeup",                 // مطلوب — makeup / haircare / fragrance / leather / accessories / tools
  brand: "Cybele",                      // مطلوب — بأي حروف كبيرة/صغيرة عادي، هيتحول تلقائي لرابط فلترة
  price: 230,                           // مطلوب — رقم بدون عملة
  salePrice: null,                      // اختياري — رقم لو في خصم، أو null لو مفيش
  tone: "#8C2F39",                      // مطلوب — لون Hex احتياطي يظهر لو مفيش صورة
  stock: 42,                            // مطلوب — رقم؛ 0 = Sold Out تلقائي، 1-5 = Almost Gone تلقائي
  customTag: "Bestseller",              // اختياري — أو null

  // كل ده اختياري — أي حقل فاضي، القسم بتاعه بيختفي من صفحة المنتج تلقائي
  description: "...",
  keyBenefits: ["...", "..."],
  howToUse: ["...", "..."],
  suitableFor: ["...", "..."],
  specifications: [{ property: "Format", details: "Matte Lipstick" }],
  faq: [{ question: "...", answer: "..." }],

  variants: [
    { colorName: "Cherry Bomb", tone: "#8C2F39", image: "https://...", available: true }
  ],
}
```

## أهم نقطة — الصور

مش لازم تعرف مين هيستضيف الصور دلوقتي. المطلوب بس إن الشخص اللي
هيبعت الداتا يحط في `variants[i].image` **رابط https كامل وشغال**
لأي مكان مستضاف عليه الصورة (Cloudinary, imgur, S3, دومين بتاعهم
الخاص، أي حاجة). الموقع مظبوط يقبل صور من **أي دومين** من غير أي
إعداد إضافي (`frontend/next.config.js` فيه `remotePatterns` مفتوح
لأي https host بالفعل).

- لو لون معين لسه مفيش له صورة، سيب `image: null` أو امسح الحقل خالص
  — الموقع هيعرض بلاطة لونية (Swatch) بدل الصورة تلقائيًا، مش هيبوّظ
  حاجة.
- لو رابط صورة اتبعت وطلع باظ (404، الدومين اتشال بعدين...)، الموقع
  برضو بيرجع للـ Swatch اللوني تلقائيًا بدل ما يعرض أيقونة "صورة
  متكسرة" — الكومبوننت `frontend/components/ProductImage.jsx` هو
  المسؤول عن الحماية دي.
- الصور بتتحمّل عن طريق `next/image`، يعني بيحصلها ضغط وتصغير وتحويل
  صيغة تلقائي (WebP/AVIF) على حسب الجهاز — من غير أي مجهود إضافي منك
  أو من الشخص اللي بعت الداتا.

## لو الداتا جاية بشكل مختلف تمامًا

لو الشخص هيبعت الداتا في شكل تاني (أسماء حقول مختلفة، أو ملف Excel/CSV
بدل JSON، أو حتى داتابيز MongoDB منفصلة عنده هو)، أنسب حاجة إنك
تبعتلي عينة (10 منتجات كفاية) من الشكل اللي هيجيلك، وهكتب سكريبت
تحويل (migration script) صغير يحوّل الشكل بتاعهم لنفس الـ Schema فوق
تلقائيًا، بدل ما حد يعمل ده يدوي منتج منتج.
